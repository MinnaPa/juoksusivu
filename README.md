# Juosten pitkin Suomea

Tämä on web-kehittämisen kurssin harjoitustyö. Sivuston tarkoituksena on esitellä Suomen kymmenen suurimman kaupungin juoksutapahtumia ja toimia alustana maratonhaasteelle.

## Linkit
* [Sivusto livenä (GitHub Pages)](https://minnapa.github.io/juoksusivu/)

## Projektin tila
Tätä sivustoa tehdään kurssin aikana vaiheittain.
* **Vaihe 1 (Suoritettu):** 
  Sivuston alustava suunnittelu, HTML5-perusrakenne ja kansiorakenne luotu. Versiohallinta (Git) ja julkaisu GitHub Pages -alustalla otettu käyttöön.
* **Vaihe 2 (Suoritettu):** 
  Semanttinen HTML-rakenne. Yhtenäinen visuaalinen ilme, väriteema ja typografia (Google Fonts) toteutettu ulkoisella CSS-tiedostolla.
* **Vaihe 3 (Suoritettu):** 
  Sivuston laajennus kolmeen sivuun (Etusivu, Kaupungit, Tapahtumat) toimivalla navigaatiolla. Pääasiallisena layout-ratkaisuna CSS Grid (kaupunkikortit ja Strava-tulokset) sekä tukevana ratkaisuna CSS Flexbox (navigaatio). Sisältöalueiden muotoilu korteiksi.
## Täytetyt vaatimukset
* **HTML5** (Semanttiset elementit: header, nav, main, section, footer)
* **CSS3** (Grid, Flexbox, Box Model, pseudoluokat)
* **Git & GitHub** (Versionhallinta ja sivuston hostaus)
